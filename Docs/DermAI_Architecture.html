DermAI — System Architecture

Skin-disease screening · ConvNeXt-Tiny classifier · MobileSAM localization · LLM cross-questioning · Doctor consultation

Patient Doctor Administrator Auth / RBAC API Gateway AI Pipeline LLM Backend Consultation

1 · Users & Role-Based Login

🧑 Patient

🔐 Patient Login
Flutter App + Web App
  • Sign up / log in
  • Capture or upload skin image
  • Tap affected body region
  • Answer LLM symptom questions
  • View result & advice
  • Request doctor consultation
  • View past sessions

👨‍⚕️ Doctor

🔐 Doctor Login
Doctor Dashboard (Web)
  • Log in (verified account)
  • View patient case queue
  • Read AI report + transcript
  • Live video / async chat
  • Write notes & advice
  • Set availability status

🛡️ Administrator

🔐 Admin Login
Admin Panel (Web)
  • Secure admin log in
  • Manage patients & doctors
  • Verify / approve doctor credentials
  • Usage & diagnosis analytics
  • Monitor model performance
  • Manage disease info & question banks
  • Audit logs & compliance
credentials all 3 roles authenticate centrally

2 · Authentication & Authorization

🔥 Firebase Authentication
Email / Google sign-in · issues ID token for every login
🧭 Role-Based Access Control (RBAC)
Token carries role claim → routes to Patient / Doctor / Admin scope & permissions

3 · API Gateway

⚡ FastAPI Gateway  ·  REST + WebSocket
Verifies token on every request · routes by role · streams the LLM chat
/diagnose   ·   /chat (WS)   ·   /finalize   ·   /consult   ·   /admin   ·   /history

4 · AI Diagnostic Pipeline  (GPU server)

🖼️ Preprocess
resize · normalize · blur check
🧠 ConvNeXt-Tiny
classifies the whole image → disease + confidence + entropy
whole image, not a crop
✂️ MobileSAM
lesion mask → overlay + area / severity
overlay only
🚦 Decision Gate
Healthy · Out-of-distribution · Normal
📋 Prompt Builder → Clinical Brief (JSON)
{ disease, confidence, body_region (from UI tap), severity, image_quality }

5 · LLM Cross-Questioning

🔁 LLM Orchestrator
State machine: reassure (healthy) · triage (OOD) · ask ≤4 clinical questions · fuse image + answers
💬 LLM Engine
OpenAI API (demo) / local Llama 3 · Mistral — receives the brief, never the raw image
persist & serve

6 · Backend Services & Consultation

🗂️ Firestore
sessions · chats · diagnoses · doctor queue · admin data
📦 Cloud Storage
uploaded images (private per-user)
🔔 Cloud Messaging
push: doctor reply / consult start
🎥 Twilio / Jitsi
live video consultation (patient ↔ doctor)
💬 Async Chat
message-based consult + AI report handoff
⚠️ Build note: ConvNeXt was trained on whole images, so MobileSAM is used for the visual overlay & severity only — never as the classifier's input. Confidence / OOD thresholds in the Decision Gate must be calibrated on a leakage-free validation set (split before augmenting). Body region is taken from the patient's tap, not a model.
